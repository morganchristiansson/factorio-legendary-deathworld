custom-spawn-rates settings formatter

Box is the single-line value pasted into the mod settings UI. Pretty is the grouped human view (# headings, one entry per line). Works for spawn and tech settings — both share ; entries and name: sections. The mod ignores # comments at load, so headings survive the round trip.

Box (single line)

Pretty (grouped)

Pretty → Box drops blank lines, strips trailing ,/; per line, and joins the rest with "; " — except lines starting with {, which rejoin the previous line with "," (brace groups of one op). # headings are kept — the mod strips them. A repeated name: header is never emitted (re-opening a section would discard its earlier entries). Headings must not contain ;.
